# Numerical Integration

Приложение для **численного вычисления определённого интеграла** с визуализацией результата на графике.
Проект ориентирован на Windows и предоставляет удобный GUI на WinForms для сравнения нескольких методов интегрирования.

## Что умеет

- Вычисляет определённый интеграл функции на отрезке `[a, b]`.
- Поддерживает несколько численных методов:
  - метод левых прямоугольников;
  - метод правых прямоугольников;
  - метод средних прямоугольников;
  - метод трапеций;
  - метод Симпсона.
- Строит график функции и визуально показывает разбиение для выбранного метода.
- Позволяет загружать табличные данные из `.txt`/`.csv` и интегрировать их через линейную интерполяцию.
- Даёт возможность сохранить построенный график в `PNG/JPEG/BMP`.

## Технологии

- **C# / .NET 6**
- **Windows Forms** для графического интерфейса.
- Собственная библиотека проекта:
  - модуль численного интегрирования (`src/Integral`);
  - математический парсер выражений (`src/Parser/MathParser`);
  - парсер табличных (аналоговых) данных (`src/Parser/AnalogParser`).

Целевой фреймворк: `net6.0-windows10.0.22000.0`.

## Как это работает

1. Пользователь вводит:
   - нижнюю границу `a`;
   - верхнюю границу `b`;
   - математическое выражение `f(x)`;
   - точность `Delta`.
2. Парсер преобразует строку функции в вычисляемое выражение.
3. Для каждого выбранного метода запускается итерационный расчёт:
   - число разбиений `n` увеличивается,
   - интеграл пересчитывается,
   - процесс продолжается, пока разность между соседними приближениями не станет меньше `Delta`.
4. Для каждого метода открывается отдельное окно с:
   - графиком функции;
   - геометрической визуализацией метода;
   - итоговым значением интеграла и количеством разбиений.

Если `a > b`, границы автоматически меняются местами, а знак результата корректируется.

## Формат входных данных для файла

Для загрузки аналоговых данных используйте файл, где каждая точка задаётся как:

```text
x;y
```

Точки можно располагать через пробелы или переносы строк.

Пример:

```text
0;0
1;1
2;4
3;9
```

На основе точек приложение строит линейную интерполяцию и интегрирует полученную функцию.
